### 📖 第 15 章：用 Hooks 終結 AI 的機率性失誤（Hooks Fundamentals: 
Deterministic Behavior in a Probabilistic System）

*   **(a) 操作步驟與指令**：
    *   **核心概念與層級**：Hook 為外掛於 LLM 之 Shell 
指令，於指定生命週期事件強制觸發 [30, 31]。設定檔可設於全域 
`~/.claude/settings.json`、專案 `.claude/settings.json`，或個人不納入版控的 
`.claude/settings.local.json` [31, 32]。
    *   **要建立的檔案與 JSON 設定重點**：
        1.  **PostToolUse 格式化 Guard**：於寫入檔案後自動執行 Prettier 格式化 
[33, 34]：
            ```json
            {
              "hooks": {
                "PostToolUse": [
                  {
                    "matcher": "Edit|Write",
                    "hooks": [
                      {
                        "type": "command",
                        "command": "npx prettier --write 
\"$CLAUDE_TOOL_INPUT_FILE_PATH\""
                      }
                    ]
                  }
                ]
              }
            }
            ```
        2.  **PreToolUse 安全 Gate**：阻止修改敏感 `.env` 檔（Exit Code `2` 
進行硬性阻斷，將 stderr 反饋給 Claude）[35, 36]：
            ```json
            {
              "hooks": {
                "PreToolUse": [
                  {
                    "matcher": "Edit|Write",
                    "hooks": [
                      {
                        "type": "command",
                        "command": "jq -e '.tool_input.file_path | 
test(\"\\\\.env$\")' > /dev/null && { echo 'Editing .env files is not allowed.' 
>&2; exit 2; } || exit 0"
                      }
                    ]
                  }
                ]
              }
            }
            ```
    *   **CLI 指令與除錯**：
        *   在 Claude Code 中輸入 `/hooks` 開啟互動式編輯器與檢驗介面 [22]。
        *   使用 `/doctor` 診斷配置錯誤 [22]。
        *   **重啟生效**：新增或修改 Hook 設定後，**必須重啟 Claude Code 
Session**（重新執行 `claude`）新 Hook 才會生效 [22]。
*   **(b) 範例專案或 GitHub 網址**：**無**。
*   **(c) 需要的外部環境或帳號**：Claude Code CLI、Node.js / npm（供 `npx 
prettier` 使用）[37]、`jq` 命令列工具（供 JSON 解析使用）[36]。
