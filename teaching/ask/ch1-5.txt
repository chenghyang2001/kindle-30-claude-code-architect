            ```yaml
            ---
            name: commit-message
            description: Generates a conventional commits message from the 
currently staged changes in a git repository. Use whenever the user asks for a

            allowed-tools: Bash, Read
            ---
            ``` [20, 22]
        *   **Markdown Body 流程步驟**：
            *   Step 1: 檢視 staged 變更（執行 `git diff --cached`；若無則看

            *   Step 2: 選擇 Commit 類型（`feat`, `fix`, `refactor`, `docs`,

            *   Step 4: 撰寫摘要（72 字內、祈使句、不首字大寫、不加句號）[22]。
            *   Step 5: 撰寫內文（非微小變更加簡短說明）[23]。
            *   Step 6: 標註破壞性變更（`BREAKING CHANGE:`）[23]。
            *   Step 7: 以單一程式碼區塊輸出 commit 訊息 [23]。
