# code-review（專案版）

## 檢查清單
1. **正確性**：迴圈邊界（off-by-one）、四捨五入、邊界值（0、空陣列、負數）。
2. **安全性**：輸入驗證、`eval`／動態執行、機密外洩。
3. **可讀性**：命名、函式長度 > 30 行、魔術數字。

## 輸出格式
| 嚴重度 | 檔案:行 | 問題 | 建議 |
|---|---|---|---|
| 🔴 必改 / 🟡 建議 / 🟢 備註 | ... | ... | ... |

只回報，不修改檔案。安全面的深度稽核交給 `security-auditor` subagent。
