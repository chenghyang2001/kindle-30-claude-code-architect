# landing-copy（產品登陸頁文案）

## 輸入
- 產品名稱、一句話描述、目標客群、2~3 個核心賣點（缺的就合理假設並標註「假設」）

## 輸出格式（Markdown）
1. **主標**（≤ 20 字，講結果不講功能）
2. **副標**（≤ 40 字，說明怎麼做到）
3. **三個利益點**：每點「粗體標題 + 一句說明」
4. **CTA 按鈕文字** 2 個備選
5. **FAQ** 3 則（價格、退款、適合誰）

## 規則
- 繁體中文、台灣用語；避免誇大字眼（「最強」「保證」）
- 只輸出文案，不寫檔，除非使用者要求
