# invoice-check（帳務檢查）

## 輸入
CSV 或表格，欄位至少：發票號碼、客戶、金額、開立日、到期日、狀態（已收/未收）

## 檢查項目
1. 發票號碼重複
2. 金額 ≤ 0 或非數字
3. 未收且已過到期日 → 逾期（列逾期天數）
4. 公司客戶缺統編（若有統編欄）

## 輸出
- 摘要：總筆數、總金額、已收、未收、逾期金額
- 異常表：發票號碼｜問題｜建議動作
- 只讀不改原始檔
