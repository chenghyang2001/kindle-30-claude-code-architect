# launch-checklist（上線清單）

逐項詢問或檢查專案檔案，輸出 `- [x]` / `- [ ]` 清單：

## 產品
- [ ] 核心流程手動走過一次（註冊→購買→收到產品）
- [ ] 錯誤頁（404/500）有友善訊息
## 金流與法務
- [ ] 金流測試交易 + 退款流程
- [ ] 隱私權政策、服務條款、退款政策頁
## 曝光
- [ ] title / meta description / OG 圖
- [ ] 登陸頁文案定稿（可用 landing-copy）
## 營運
- [ ] 錯誤監控與上線通知
- [ ] 資料庫備份 + 回滾步驟寫好
- [ ] 客服信箱可收信（可用 customer-reply 準備範本）

## 規則
- 最後列出「未完成項目」與建議優先順序；不自動部署
